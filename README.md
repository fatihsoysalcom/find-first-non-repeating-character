# Find First Non-Repeating Character

This example demonstrates a common Dev Challenge problem: finding the first non-repeating character in a string. It showcases algorithmic thinking, string processing, and dictionary usage to efficiently solve the problem, reflecting skills often tested in technical challenges.

## Language

`python`

## How to Run

Save the code as main.py.
Run from your terminal: python main.py
